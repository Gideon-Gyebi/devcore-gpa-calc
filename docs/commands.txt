# COMMANDS FOR DEVELOPMENTS


1. gcc main.c src/*.c -Iinclude -o obj/gpconv --> [command used to compile "main" executable]

2. gcc test/test_gpconv.c src/gpconv.c -Iinclude -o obj/test_gpconv --> [command used to compile "test_gpconv" executable]

3. ./obj/<executable file name> --> [Git bash command to run compile program]

4. \obj\<executable file name> --> [CMD / Powershell command to run compile program]
