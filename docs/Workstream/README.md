# Workstreams

This folder organizes guides and handoff deliverables by project workstream. The workstreams follow [Requirements and Data Model Team Discussion V2](../archive/Requirements_and_Data_Model_Team_Discussion_v2.md), section 6, and the settled outcomes in [GKGDev Core 5 Requirements Decisions and Agreed Specifications](../archive/GKGDev_Core5_Requirements_Decisions_and_Agreed_Specifications_Styled.md).

## Folder structure

Each workstream has its own folder with separate `Guide` and `Deliverable` subfolders:

```text
docs/Workstream/
  Data Model and API Design/
    Guide/        Workstream guide files
    Deliverable/  Role handoffs and work products
```

Use the same structure for later workstreams. Keep team-facing handoffs in `Deliverable`; keep instructions and reference guides in `Guide`.
