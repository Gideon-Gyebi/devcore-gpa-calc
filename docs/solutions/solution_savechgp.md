# Algorithm
1. Receive the credit hour, grade point, and storage position.
2. Save the credit hour in the specified storage position.
3. Save the grade point in the same storage position.
4. Return control to the calling function.

```

Storage position (same as course number)
↓

↓
```

# Pseudocode
1. START
2. INPUT storage, index, creditHour, gradePoint
3. STORE creditHour at the specified storage position

5. RETURN
6. END
