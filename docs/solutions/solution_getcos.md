# Algorithm
1. Display the list of available courses.
2. Prompt the user to select a course number.
3. Read the user's input.
4. Check whether the input is between 1 and 6.
5. If the input is invalid, display an error message and repeat Step 3.
6. Return the selected course number.

```
Display courses
↓
Read input
↓
Validate
↓
Output
```

# Pseudocode
1. START
2. Display list of courses
3. Prompt user to enter course number
4.  Read course number
5. IF course number is invalid THEN
6.  Display error message
7.  ENDIF
8. UNTIL course number is valid
9.  RETURN course number
