# Algorithm
1. Define a GPA record structure containing the required course calculation data.
2. Include credit hour and grade point as elements of the record.
3. Define the maximum number of records the application can store.
4. Create an array of GPA records using the defined structure.
5. Make the record storage available for use by the GPA calculation functions.

```
Define GPA Record Structure
↓
Add Credit Hour and Grade Point Elements
↓
Set Maximum Number of Records
↓
Create GPA Record Storage Array
↓
Provide Storage for Calculation Functions
```
