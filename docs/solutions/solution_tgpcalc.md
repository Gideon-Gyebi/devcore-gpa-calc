# Algorithm
1. Ask the user the number of courses they want to enter.
2. Prompt the user to enter the number of courses.
3. Read the user's input.
4. for each courses ;display the output.
5. If the input is invalid, display an error message and repeat Step 3.
6.Repeat the entire process for the user to enter the details of the second course.
7.Print and return the total grade point.

```
User input for number of courses
↓
Read input
↓
Validate
↓
Output
↓
Repeat the process (for the number of courses the user inputted)
↓
Calculate the total Grade point
↓
Display the output for the total grade point
```

# Pseudocode
1. START
2. Ask the user the number of courses to run.
3. Prompt user to enter the number of courses
4.  Read input
5. IF course (an integer value) is invalid THEN
6.  Display error message
7.  ENDIF
8. UNTIL course(an integer value) is valid
9. Repeat the loop for the number of courses the user inputted.
10. Calculate the total grade point.
11. Print the total grade point.
