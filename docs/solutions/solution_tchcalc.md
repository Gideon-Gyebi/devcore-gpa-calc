# Algorithm
1. Receive the GPA record storage and the number of stored courses.
2. Initialize the total credit hour to zero.
3. Read the credit hour from each stored record.
4. Add each credit hour to the total credit hour.
5. Return the total credit hour.

```
Receive Storage
↓
Initialize Total Credit Hour
↓
Read Credit Hour
↓
Add to Total
↓
Repeat for All Records
↓
Return Total Credit Hour
```

# Pseudocode
1. START
2. INPUT GPA record storage and number of courses
3. INITIALIZE total credit hour to 0
4. REPEAT for each stored course
5.  READ credit hour from the current record
6.  ADD credit hour to total credit hour
7. END REPEAT
8. RETURN total credit hour
9. END
