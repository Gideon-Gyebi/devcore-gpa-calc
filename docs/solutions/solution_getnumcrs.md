# Algorithm
1. Prompt the user to enter the number of courses.
2. Read the user's input.
3. Validate the input format.
4. Validate that the number of courses is within the allowed range.
5. Check for extra characters in the input.
6. Display an error message if any validation fails.
7. Repeat until a valid input is received.
8. Store the validated number of courses.
9. Return the number of courses.

```
Prompt User
↓
Read Input
↓
Validate Input
↓
Display Error (if invalid)
↓
Store Number of Courses
↓
Return Number of Courses
```

# Pseudocode
1. START
2. PROMPT user to enter the number of courses
3. READ number of courses
4. IF number of courses is invalid THEN
5.  DISPLAY error message
6.  RETURN to Step 2
7. ENDIF
8. STORE number of courses
9. RETURN number of courses
10. END
