ESCAPE SPECIAL CHARACTERS
---------------------------------------------------------
Use a backslash (\)

Example:
\*Not Italic\*
\# Not a Heading

LINE BREAKS
---------------------------------------------------------
Leave a blank line between paragraphs.

Alternatively, end a line with two spaces
to force a new line.

BEST PRACTICES
---------------------------------------------------------
• Use Heading 1 (#) only once per document.
• Keep heading levels in order (# → ## → ###).
• Specify the language in code blocks.
• Keep tables aligned for readability.
• Use task lists to track project progress.
• Preview your document before committing changes.
